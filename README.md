## 📖 About the Project
The **School ERP System** is an advanced web-based platform that digitalizes academic and administrative tasks.  
It helps schools automate daily operations such as admissions, attendance, fees, library, staff management & communication.

---

## ✨ Key Features

| Module | Description |
|--------|-------------|
| 👨‍🎓 Student Management | Register, modify, and track student info |
| 🧑‍🏫 Staff Management | Teachers, roles & salary handling |
| 🧾 Attendance Tracking | Daily attendance & reports |
| 📚 Library System | Book issues, returns, inventory |
| 💳 Fees Management | Fee payment, due notifications |
| 🔐 Secure Login | Role-based (Admin/Staff/Parent) |
| 📊 Analytics | Student performance insights |
| 🗄️ Database Backup | Data export for admin |

⚙️ Setup & Run Instructions
# 1️⃣ Create a virtual environment
python3 -m venv .venv

# 2️⃣ Activate the virtual environment
source .venv/bin/activate

# 3️⃣ Install required dependencies
pip install -r requirements.txt

# 4️⃣ Create training image directory (if not exists)
mkdir TrainingImage

# 5️⃣ Run the Attendance Management System
python3 attendance.py

# 6️⃣ Deactivate virtual environment (after closing the app)
deactivate

## 📂 Folder Structure

│
├── 📁 frontend/               # UI Components (HTML, CSS, JS, Bootstrap)

│   └── public/                # Static files
│

│   ├── controllers/           # Business Logic
